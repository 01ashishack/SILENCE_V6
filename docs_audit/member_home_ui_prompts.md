# Member Home — Screen Prompts for Antigravity

**Theme:** Warm cream (#FBF5EE) bg, orange (#E65C00) header/accents, white cards, rounded corners 12-16px, Inter/Outfit fonts.

---

## Stage 1 — Fresh Install (No Profile, No Library)

**Bottom Nav:** 3 tabs — Home | Explore | Profile

**Header:** Orange curved bottom. "Welcome to SILENCE!" + subtitle. Logo left, bell right.

**Content:**
- **Complete Your Profile card** — White card, orange left border. Title, short instruction text, "Get Started" button.
- **How SILENCE Works card** — White dashed border. 3 rows: (1) Complete profile, (2) Find a library, (3) Scan & study. Each with icon + text.

---

## Stage 2 — Profile Complete, No Library

**Bottom Nav:** 3 tabs — Home | Explore | Profile

**Header:** Orange curved. "Ready to Study!" + subtitle. Green checkmark near greeting.

**Content:**
- **Celebration card** — Green tint, checkmark. "Profile Complete ✓" message.
- **"Find a Library" button** — Orange, full width. Opens Explore screen.
- **"Join with Code" button** — Outlined.
- **Libraries Near You** — 2 library cards: photo, name, rating, distance, price.

---

## Stage 3 — Active Member (Has Memberships)

**Bottom Nav:** 4 tabs — Home | Analytics | History | Profile

**Header:** Orange curved. "Good afternoon, [name]" + subtitle. Bell with red badge.

**Content:**
- **Quick Actions** — Horizontal row: Check In, Book Seat, Request Hold, View Library. Circle icons with labels.
- **Today's Attendance card** — Green if checked in (time + live timer + check out btn), grey if not (check in btn).
- **Study Streak card** — Flame icon, streak count, 7 day circles (green = done, grey = missed).
- **My Memberships** — Cards with color-coded left border. Library name, seat, shift, plan, price, expiry bar, action buttons (Renew, Seat Chg, More).
- **Recent Activities** — Timeline list: time + action + location with colored dots.
- **Announcements** — Orange border (unread) and grey border (read) items.

**FAB:** Orange QR scanner button bottom right.

---

## Stage 4 — Returning (Exited Library)

**Bottom Nav:** 4 tabs — Home | Analytics | History | Profile

**Header:** Orange curved. "Welcome back!" + subtitle.

**Content:**
- **Previous Membership card** — Amber left border. Library name, end date, duration. "Rejoin Now" button. Trophy stat: "120 hours in 45 days".
- **Quick Actions** — Horizontal row: Rejoin, Find New Library, Join with Code.
- **Streak card** — "Your Best Streak: 12 days" with flame. Motivational text.
- **"Find a Library" button** — Orange, full width.
- **Suggested Libraries** — 2 preview cards with photo, name, rating, distance.
- **Last Activity** — Small card showing last active date.

**FAB:** Orange QR scanner button.

---

## Explore Screen (Full Screen, No Bottom Nav)

**Header:** Orange. "Find a Study Zone" + back arrow + bell.

**Content:**
- Search bar with icon
- "Join with Code" outlined button
- Library list: each card has photo, name, verified badge, address, distance tag, amenity chips (WiFi, AC, Lockers), price, free trial tag, star rating
- "Suggest a Library" form at bottom

---

## Bottom Sheets

- **Seat Change** — Title, library name, current seat chip, reason text field, info box, Cancel + Submit
- **Membership Options** — 3 options: Hold/Pause, Change Seat, Exit Library (red)
- **Exit Confirmation** — Warning icon, text, dues caution box, Confirm Exit (red) + Cancel
